# CutPlan v0.6.5 — Edge Banding Workspace Verification

## User-facing changes

- The cutting-list table contains only Reference, Length, Width, Quantity, Rotation, and Delete. No edge-banding values or `ED` table column are rendered.
- A prominent, full-width **Open Edge Banding** button appears immediately below the ROWS heading and before the list. It is not hidden inside the narrow table or at the far right of the row.
- The button opens a viewport-filling editor. The part/reference selector and all four values (0.8 mm length/width and 2 mm length/width) are shown in the same panel.
- Close and Escape return to the cutting list. Changes save to the selected row; changing the selected reference does not copy values to another row.
- The underlying optimizer, geometry, part schema, CSV parsing and edge-band totals were not changed by this UI patch.

## Real browser interaction test

Run:

```bash
python3 test-banding-interaction.py
```

Chromium test performs these actions, rather than merely checking markup:

1. Loads the app and inserts three independent test parts.
2. Confirms there is no ED/banding table heading or banding input inside the table.
3. Measures the table scroll width and client width and verifies no horizontal scroll at 542 px and 467 px viewports.
4. Clicks **Open Edge Banding**, waits for the dialog to open, selects part 1KB and enters `0.8 mm: length 2, width 1` and `2 mm: length 1, width 2`.
5. Switches to 2KB and verifies its values are independent and remain at zero.
6. Closes and reopens the dialog, reselects 1KB and verifies all four values are still displayed.
7. Verifies Close and Escape exit the dialog, and confirms the 467 px dialog fits the viewport.

Observed result:

- Dialog open/edit/switch/reopen/close/Escape: PASS.
- No edge-banding table column: PASS.
- At 542 px: document width 542 px; table scroll width equals its client width (474 px).
- At 467 px: no document or table horizontal overflow.
- Full-width launcher width at 542 px: 450 px.
- No browser page errors during the test.

## Correction to previous release verification

The v0.6.4 Playwright test script attempted to select the part dropdown before opening the dialog, so the input was hidden and the interaction test timed out. The earlier v0.6.4 delivery text overstated the live open/edit/close verification. v0.6.5 corrects the test ordering and carries out the actual browser interactions listed above. The v0.6.4 source already omitted the ED column, so a screenshot still showing ED indicates that an older project copy was being served. Use the folder containing this v0.6.5 `index.html` as the HTTP server root and hard-refresh the browser.

## Scope

This release fixes the edge-banding workflow and makes its entry point conspicuous. It does not change the optimizer or claim any new nesting or waste-reduction improvement.
