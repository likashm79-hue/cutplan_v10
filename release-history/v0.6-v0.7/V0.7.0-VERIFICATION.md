# CutPlan v0.7.0 — Final verification

**Date:** 10 November 2026  
**Base:** CutPlan v0.6.6

## Delivered changes

1. All parsed cutting-list rows appear in one continuous table, with per-row summaries for both 0.8 mm and 2 mm edge banding. Each summary displays length-side (`L`) and width-side (`W`) counts. The full row set is not hidden behind a short scrolling viewport.
2. Each row has an **Edit** action that opens the existing edge-banding dialog at the selected reference. Saved values refresh the main table immediately.
3. Waste/offcut regions remain amber and are not labeled with W01/W02 markers or text inside the drawing.
4. The amber waste/offcut highlights are retained in print/PDF output.
5. Each board is on its own A4 portrait page. The board drawing uses the near-full page height; small-part marker explanations are placed in a compact right-hand schedule.
6. The board name is centered above the board drawing and printed in bold.

## Scope and limitations

The parser, nesting engine, cut-tree validator, worker interface and drawing layout engine were not rewritten for this UI/print release. Physical printer calibration is not tested; use 100% / actual-size printing and validate real stock dimensions, kerf, grain direction and saw sequence before production.
